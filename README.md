# 🚀 Agency Website

> A modern, ultra-responsive digital agency portfolio built with **React**, **Tailwind CSS**, and **Vite**.

## 🌟 Overview

This project is a high-performance Single Page Application (SPA) designed to showcase the services, portfolio, and team of a modern digital agency. It features a stunning UI with glassmorphism effects, smooth animations, and a seamless dark/light mode experience.

## ✨ Key Features

- **🎨 Modern Aesthetic**: Clean, professional design with glassmorphism and gradient accents.
- **🌓 Dark/Light Mode**: Fully integrated theme switcher with local storage persistence.
- **📱 Fully Responsive**: Optimized for all devices, from mobile phones to extra-large desktop screens.
- **⚡ Blazing Fast**: Powered by Vite for instant hot module replacement and optimized builds.
- **🧱 Component-Based**: Modular architecture using React best practices.
- **🎬 Smooth Animations**: Custom CSS animations and transitions for an engaging user experience.

## 🛠️ Technology Stack

- **React 19**: The library for web and native user interfaces.
- **Tailwind CSS 4**: A utility-first CSS framework for rapid UI development.
- **Vite**: Next Generation Frontend Tooling.
- **React Icons**: Popular icons in your React projects easily.
